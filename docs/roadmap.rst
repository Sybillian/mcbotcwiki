Modpack Roadmap
===============

The following is the order of explicitly planned changes and additions to the pack. It is not comprehensive - most updates will have lots of little things and bug fixes in addition to the listed items. Things here may also get moved around!

1.6.0
-----
* Banshee functionality
* Organ Grinder functionality
* New Quick Actions menu for Storytellers
* New Bag menu for Storytellers
* Open nighttime voice chat
* Text-based neighbor whispering
* Significantly simpler server-side installation

1.6.1
^^^^^
* All remaining unlocalized text changed to translatable strings
* Manual player seating
* Generic Traveller functionality - this will likely not include Thief, Beggar, Bureaucrat, and Matron.
* Hand raising system

1.6.2
^^^^^
* Wraith functionality
* Major optimizations for repetitive FancyMenu variables
* In-game Grimoire sharing for Spy & Widow
* Finish building the damn trees

1.6.3
^^^^^
* Roshambo rework
* Pointing rework
* Jinx screen implementation
* God of Ug functionality
* Remaining Travellers functionality

1.7.0
-----
* Homebrew character support

1.7.1
^^^^^
* Night cards system for Storytellers to communicate with players without speaking to them.

1.8.0
-----
* Support for the creation of custom maps
